# 🏠 Mi Casa  

¡Bienvenido a la actividad! Aquí pondrás en práctica los conocimientos adquiridos en la sesión de **Git & GitHub**.  

---

## 📌 Descripción  
Esta es **Mi Casa 🏠**, y tu misión será **amoblarla**. Para lograrlo, cada grupo será responsable de una habitación específica.  

La casa se compone de:  
1 Habitación principal  
2 Sala  
3 Cocina
4 Baño
5 Terraza

¿Fácil, verdad? 😄  

---

## ⏱️ Reto  
El reto debe cumplirse en **12 minutos**:  

- **2 minutos** → Distribución de grupos y asignación de habitaciones.  
- **10 minutos** → Cada grupo deberá:  
  1 . Crear una **rama** con el nombre de su habitación.  
  2 . Cambiarse a esa rama.  
  3 . Cada integrante hará su **commit** agregando los muebles y elementos que desee para “amoblar” su habitación.  
  4 . Subir los cambios a GitHub.  

---

# 🏠 Flujo de trabajo con Git y GitHub

## 🔽 1. Clonar el repositorio
(Se hace solo la primera vez)
💻 git clone https://github.com/AndresSandoval123/Rompe_Hielo_C11.git

## 📂 2. Entrar a la carpeta del repositorio
💻 cd Rompe_Hielo  

## 🌱 3. Crear y moverse a la rama de tu habitación
💻 git checkout -b nombre-de-la-habitacion  

## ✏️ 4. Agregar los cambios
💻 git add .  

## 💾 5. Hacer un commit
💻 git commit -m Agrego muebles a la habitación  

## ⬆️ 6. Subir la rama a GitHub
💻 git push -u origin nombre-de-la-habitacion
